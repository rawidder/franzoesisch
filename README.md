# Französisch-Grammatik

Lern-App für die französische Grammatik (für Deutschsprachige): Merkblätter, Übungen mit Sofort-Korrektur und Lernkarten zu 30 Kapiteln – von der Aussprache bis zum subjonctif, mit Verbtabellen und einem Kapitel zur Frankophonie. Eine einzige HTML-Datei, optimiert fürs iPhone.

**App öffnen:** https://rawidder.github.io/franzoesisch/ (sobald GitHub Pages aktiviert ist)

Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

## Inhalte bearbeiten

Die Kapitel liegen als JSON in `quelle/kapitel/`. Nach Änderungen `cd quelle && python3 build.py` ausführen – das schreibt die Inhalte neu in `index.html`.
